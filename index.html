bio-cpu

A computer architecture modelled on gene regulation. DNA is read-only program memory, protein counts are working memory, and every gene runs in parallel each tick with no program counter.

Program

How it maps to a computer

Genes
Program memory (ROM). The running cell can read genes but never rewrite them.
Protein types
Memory addresses.
Protein counts
The values stored at those addresses (RAM).
if A < 10
A conditional: the gene only runs while the threshold holds.
Each tick
Every gene reads the same snapshot and may fire at random. Its output is added, never overwritten, so parallel genes can't race.
Decay
Each molecule can be lost each tick, so values fade unless a gene keeps writing them.
Pulses
Input from outside the cell.
Language reference 
protein NAME [init N] [decay P]
gene NAME makes PROTEIN [AMOUNT] rate R [if COND and COND ...]
    R = probability per tick (0.5) or linked to a protein (0.02*S)
    COND = PROTEIN < N   or   PROTEIN > N
pulse PROTEIN AMOUNT at TICK
